# Agrinho 2026

## Tema
Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente.

## Assunto Escolhido
- Agricultura de precisão e tecnologia no campo.

## Sobre o Projeto
Este projeto foi desenvolvido para o Concurso Agrinho 2026, na categoria Programação. A aplicação web apresenta informações detalhadas sobre como o uso inteligente da tecnologia no campo ajuda a equilibrar a produção de alimentos com a preservação ambiental.

## Objetivo
O objetivo do projeto é demonstrar como sensores, drones e dados inteligentes podem reduzir o desperdício de água e o uso excessivo de produtos químicos nas lavouras brasileiras.

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript (ES6)
- Inteligência Artificial como apoio no desenvolvimento

## Funcionalidades
- Página informativa rica em conteúdo ecológico e agrícola.
- Simulador de diagnóstico tecnológico integrado com JavaScript.
- Layout responsivo adaptado para dispositivos móveis e computadores.
