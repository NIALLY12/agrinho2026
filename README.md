# EcoAgro - Agricultura de Precisão Sustentável 🌾🤖

## 📋 Tema Oficial do Agrinho 2026
**"Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente."**

## 🎯 Assunto Específico do Projeto
- **Agricultura de precisão e a aplicação da tecnologia no campo sustentável.**

## 💻 Sobre o Projeto
Este é um portal educacional e tecnológico premium desenvolvido como projeto de Programação Web para o **Concurso Agrinho 2026**. A aplicação tem o objetivo de demonstrar de maneira teórica e prática como a tecnologia e a ciência de dados atuam no ecossistema do campo para garantir o fornecimento de alimentos mundial sem degradar os recursos naturais do nosso planeta.

## 🚀 Funcionalidades Avançadas
- **Mapeamento Conceitual:** Cartões informativos e flutuantes sobre a revolução do agronegócio e seus dilemas sustentáveis.
- **Calculadora Dinâmica Eco-Impacto:** Algoritmo que calcula, com base na área de terra digitada, a estimativa real de preservação anual de água, redução de emissão de CO₂ e contenção de químicos.
- **Quiz de Diagnóstico de Propriedades:** Questionário que analisa os métodos de manejo e retorna uma análise técnica com pontuação sobre o nível ecológico da fazenda.
- **Responsividade Total:** Interface polida para computadores, tablets ou celulares com animações fluidas via CSS Grid/Flexbox.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica e acessível.
- **CSS3:** Estilização com design system moderno, paleta de cores naturais, transições suaves e animações de entrada.
- **JavaScript (ES6):** Manipulação dinâmica de dados (DOM), lógica matemática e sistema interativo por abas.
- **Inteligência Artificial:** Utilizada como mentora tecnológica na arquitetura e refinamento lógico do código.
